Tile primitives extracted from MINI-03 and PENDON-01

Five flat colors and seven square tile shapes reproduce both source images. Each shape is one file, sized to a 0 to 100 viewBox, colored through two CSS variables (tile-a and tile-b) so the same file can be reused with any color pair with no regeneration.

Verification against the source

These eight tiles were read off MINI-03 by eye, matched to a shape id and a tile-a and tile-b color pair, then rendered from the templates above. Left is the original crop, right is the reconstruction built only from the seven files with color overrides.
